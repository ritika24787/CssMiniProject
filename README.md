
# Thala 7 Sneaker Store 👟

Thala 7 Sneaker Store is a simple sneaker shopping website made using HTML and CSS.

This project is created as a beginner web development practice project. It includes a product section, shopping cart, and checkout/payment section.

## Features

* Simple navigation bar
* Thala 7 logo design
* Search box
* Shopping cart icon
* Profile image
* Hero section with shoe image
* Shop Now button
* Customer reviews and other stats
* Product details section
* Product image gallery
* Product price and discount
* Quantity section
* Add to Cart button
* Shopping cart table
* Coupon code section
* Order summary
* Checkout section
* Payment method section
* Responsive design for smaller screens

## Technologies Used

* HTML5
* CSS3
* Font Awesome

## How to Run

1. Download or clone this project.
2. Open the project folder.
3. Make sure the `images` folder contains all the required images.
4. Open `index.html` in your browser.
5. The website will be displayed in the browser.

## Project Sections

### 1. Header

The header contains:

* Website logo
* Navigation links
* Search box
* Cart icon
* Profile image

### 2. Hero Section

The hero section shows the main Thala 7 heading, a short description, a Shop Now button, and a shoe image.

### 3. Product Section

This section contains:

* Main product image
* Product gallery
* Product name
* Product description
* Price
* Discount
* Quantity buttons
* Add to Cart button

### 4. Shopping Cart

The shopping cart section displays the selected products, quantity, price, remove button, coupon code, and total amount.

### 5. Checkout

The checkout section contains:

* Email input
* Payment method
* Card details
* Expiry date
* CVV
* Country
* Zip code
* Order summary
* Pay Now button

## Responsive Design

The website is made responsive using CSS media queries.

It adjusts the layout for:

* Desktop
* Tablet
* Mobile screens

## Note

This is a front-end practice project. The buttons, cart, search, coupon, and payment options are currently for design purposes and do not have real functionality.
